# NovelAI 提示词记录 · 电脑版 v1.0

- 类型：`Python 后端 + WebView 前端`（Flask + pywebview）
- 运行平台：Windows
- 版本：`1.0`
- 数据位置：程序目录（`prompt.json`、`picture/`；`prompt_pack/` 是「打包提示词」的输出目录，`temp/`、`log/` 为运行文件）

## 简介

一个完全本地运行的提示词管理工具：启动时在本地起一个 Flask 服务，再用 pywebview 打开窗口加载网页界面。提示词、图片、打包结果都保存在程序所在目录，不依赖网络，也不需要服务器。

## 功能

- **提示词管理**：分组、角色、版本、描述、多张封面图
- **图片本地化**：直接从本地上传图片，不再依赖图床
- **打包提示词**：把提示词打包成 `.bundle` 文件，可选密码加密（AES）
- **加载提示词**：导入 `.bundle`，支持「合并」与「替换」两种方式（含图片）
- **详情查看**：图片切换、复制指令、保存图片、编辑、删除
- **数据保护**：`prompt.json` 自动备份；检测到语法损坏时可提取内容并修复

## 相较于未发布的初代更新了什么

> 「初代」指网页前端 + Python 后端的第一版自用程序：没有版本号、没有打包功能，也不对外分发。

1. **首次确定版本号（1.0）并作为正式版本发布**
2. **新增「打包提示词」**：可导出为 `.bundle`，支持密码加密
3. **新增「加载提示词」**：支持合并 / 替换，连同图片一起导入
4. **新增提示词 UUID**，为后续的编辑、删除提供稳定标识
5. **删除操作加入确认弹窗**，避免误删
6. **新增 `prompt.json` 备份与语法损坏恢复**（提取参数 → 确认 → 修复）
7. **用 PyInstaller 打包为可分发 exe**，不再需要自己装环境
8. 沿用初代已有的模块化目录结构与图片本地存储

## 目录结构

```
pc/
├── index.html          # 主界面
├── main.py             # Flask 服务 + pywebview 窗口
├── css/                # 样式（按模块拆分）
└── script/
    ├── main.js         # 入口
    ├── api.js          # 与本地后端的接口封装
    ├── state.js        # 全局状态
    ├── utils.js        # 工具函数
    └── ui/             # 各个弹窗/组件
```

## 运行

```bash
python main.py
```

依赖：`flask`、`pywebview`、`Pillow`、`py7zr`、`pycryptodomex`（或 `pycryptodome`）。

## 打包程序（发布用）

v1.0 未附带打包脚本，使用 PyInstaller 手动打包（`-D` 单目录模式，附带 `index.html`、`css`、`script` 三个资源），**打包产物输出在 `dist/`**（如 `dist/NovelAIPromptTool/`），与程序本身的数据目录无关。

## 说明

- **提示词打包**（功能里的「打包提示词」）的输出默认位于程序目录下的 `prompt_pack/`
- 日志位于 `log/`，按日期分文件
