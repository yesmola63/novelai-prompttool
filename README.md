# NovelAIPromptTool

NovelAI 提示词记录工具的**版本存档仓库**，包含电脑版（Windows）与手机版（Android）的源码、文档和历史版本。

## 仓库内容

| 目录 | 说明 |
|---|---|
| [`v1.0/`](v1.0/) | 首个正式版本（电脑版 + 手机版），含[应用历程](v1.0/README.md) |
| [`v1.1/`](v1.1/) | 第二个版本，新增应用内检查更新等（见各端 README） |

每个版本下分 `pc/`（电脑版）与 `mobile/`（手机版），各自的说明见目录内的 `README.md`。

> 说明：`v1.0/mobile` 的源码是**根据安装包逆向重建**的（原工程已丢失），不可靠，仅供存档参考；可靠的 v1.0 行为请以该目录下 `original/` 中的 APK 为准。

## 应用历程

这个项目从最早的纯静态网页开始，经历了「网页版 → 电脑版 → 手机版」几个阶段：静态网页看图 → Cloudflare KV 存储实现添加 → 编辑/删除 → B2 存储桶（未上线）→ 网页前端 + Python 后端（本地图片）→ Kotlin 安卓版。

完整的由来、每一版的取舍，以及手机版是如何从 Buildozer / WebToApp 的失败尝试走到可用的 Kotlin 工程，都写在 **[v1.0/README.md](v1.0/README.md)** 里，感兴趣可以看看。
