# NovelAI 提示词记录 · 电脑版 v1.1

- 类型：`Python 后端 + WebView 前端`（Flask + pywebview）
- 运行平台：Windows
- 版本：`1.1`
- 数据位置：程序目录（`prompt.json`、`picture/`；`prompt_pack/` 是「打包提示词」的输出目录，`temp/`、`log/` 为运行文件）

## 简介

本地运行的提示词管理工具：Flask 在本地提供服务，pywebview 打开窗口加载网页界面；提示词、图片与打包好的提示词包都保存在程序目录，不依赖网络。

## 功能

- **提示词管理**：分组、角色、版本、描述、多张封面图
- **图片本地化**：本地上传，不依赖图床
- **打包提示词**：导出 `.bundle`，可选密码加密（AES）；打包前检查同名文件
- **加载提示词**：导入 `.bundle`，支持「合并 / 替换」
- **详情查看**：窗口式布局、图片切换、复制指令、保存图片、编辑、删除
- **数据保护**：`prompt.json` 自动备份，语法损坏时可恢复
- **应用内检查更新**（1.1 新增）

## 相较于 v1.0 更新了什么

### 新增功能

1. **应用内检查更新**
   - 启动时自动比对服务器版本，发现新版本弹窗展示更新说明
   - 「立即更新」下载安装包，实时显示进度与下载速度，完成后拉起安装
   - 「暂不更新」直接关闭；勾选「当天不再显示」后当天不再提示，次日恢复
   - 更新信息缓存在 `temp/update_cache.json`，检测不到更新时自动删除

2. **密码框明文/密文切换**（眼睛图标，打包与加载界面）

### 交互改进

3. **分类栏重做**
   - 由「左右翻页箭头」改为**横向拖动滚动**
   - 右侧箭头点击后展开全部分类（一次性列出，非分页）
   - 支持**鼠标滚轮横向滚动**
   - 当前分类自动滚动到可视区域中间

4. **分组填写重做**
   - 由「下拉框选择 + 另填新分组」改为**单个输入框**
   - 输入时自动匹配已有分组，以下拉面板列出，点击即填入
   - 命中已有分组显示绿色 ✓ 提示，新建分组显示红色提示

5. **打包界面**
   - 勾选「需要密码」后才显示密码框（带展开动画）
   - 选择「打包所有提示词」时隐藏「选择提示词」按钮
   - 打包前检查同名文件并提示

6. **选择提示词界面**：分类栏增加右侧箭头下拉，与主界面一致

### 技术改进

7. **Flask 改为多线程**，避免更新检查等慢请求阻塞页面资源加载
8. **新增 `build.bat` 一键打包脚本**（PyInstaller 单目录模式）
9. **后端接口与手机端统一**：新增 `/api/app-info`、`/api/update/*`、`/api/save-image`、打包目录轮询、同名检查、加载进度等接口，两端共用同一套前端代码

## 目录结构

```
pc/
├── index.html              # 主界面
├── main.py                 # Flask 服务 + pywebview 窗口
├── build.bat               # 一键打包脚本
├── css/                    # 样式（含 updateModal.css）
└── script/
    ├── main.js             # 入口
    ├── api.js              # 后端接口封装
    ├── state.js            # 全局状态
    ├── utils.js            # 工具函数
    └── ui/                 # 各弹窗/组件（含 updateModal.js、common/groupInput.js）
```

## 运行

```bash
python main.py
```

依赖：`flask`、`pywebview`、`Pillow`、`py7zr`、`pycryptodomex`（或 `pycryptodome`）。

## 打包程序（发布用）

```bat
build.bat
```

产物位于 `dist\NovelAIPromptTool\`（与「打包提示词」功能生成的 `prompt_pack/` 无关）。
